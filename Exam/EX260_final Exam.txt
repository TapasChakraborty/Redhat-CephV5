)Configure a Ceph RADOS block device according to the following requirements:*Create a Ceph replicated pool named ex260-pool*This pool uses 32 placement groups*From this pool, create a Ceph RADOS block device image named ex260-rbd*The image size should be 512 MB*The authentication requirement is provided in another task*Format the Ceph block device image ex260-rbd with an ext4 file system*On host client.domain8.example.com mount the Ceph block device image ex260-rbd at mount point /mnt/rbdpersistentlyAns:root@server1#ceph osd pool create ex260-pool 32 32ceph osd lspoolsceph osd pool application enable ex260-pool rbdrbd pool init ex260-poolceph osd pool ls rbd create ex260-rbd --size 512M --pool ex260-poolrbd ls ex260-poolrbd info ex260-pool/ex260-rbdssh client.lab.example.comroot@client#rbd map ex260-pool/ex260-rbd  mkfs.ext4 /dev/rbd0mkdir -p /mnt/rbdmount /dev/rbd0 /mnt/rbdecho "/dev/rbd0  /mnt/rbd  ext4  defaults,_netdev  0 0" >> /etc/fstabdf -kh /mnt/rbdecho "ex260-pool/ex260-rbd" >> /etc/ceph/rbdmapsystemctl enable rbdmapsystemctl start rbdmap========================================================================================Question 7==========>Export an RBD Image to a FileOn server1.domains.example.com export the rbd
