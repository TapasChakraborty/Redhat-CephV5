Configure a Ceph RADOS block device according to the following requirements:
*Create a Ceph replicated pool named ex260-pool
*This pool uses 32 placement groups

*From this pool, create a Ceph RADOS block device image named ex260-rbds
*The image size should be 512 MB

*The authentication requirement is provided in another task
*Format the Ceph block device image ex260-rbd with an ext4 file system
*Create Satish user who can read write on ex260-pool pool.
*On host client.domain8.example.com mount the Ceph block device image ex260-rbd at mount point /mnt/rbd

***********

$ ceph osd lspools

# Create RADOS block device ex260-rbds and size 512

$ rbd create ex260-rbd --size 512 --pool=ex260-pool

# Enable the rbd applicationwith pool ex260-pool

$ ceph osd pool appliacation enable ex260-pool rbd

# Create user satish

$ ceph auth get-or-create client.satish mon 'allow r' osd 'allow rw pool=ex260-pool' -o /etc/ceph/ceph.client.satish.keyring

# copy keyring to client machine:

$ scp /etc/ceph/ceph.client.satish.keyring root@client.domain8.example.com:/etc/ceph

# Format and mount the disk

$ ssh root@client.domain8.example.com
$ rbd --id satish map ex260-rbd --pool ex260-pool
	/dev/rbd0
$ mkdir -p /mnt/rbd 
$ mkfs.ext4 /dev/rbd0
$ vi /etc/fstab
	/dev/rbd0 /mnt/rbd ext4 defaults,_netdev 0 0 
$ mount -av
$ df -hT | grep /mnt/rbd

Deploy MDS and CephFS

Deploy a Metadata Server on your on server1.domain8.example, com of your Ceph cluster according to the following requirements:
Create a CephFS volume named cephfs01
Create the following CephFS subvolumes:
cephfs01:/ is readable and writeable and supports snapshots
cephfs01:/ is authorized with client id 01
cephfs01:/backup is read only
cephfs01:/backup is authorized with client id 02
It must be possible to manually mount the cephfs01 subvolumes on client.domains.example.com


***********

$ ceph orch apply mds cephfs0001 --placement="server1.domain8.example"
$ ceph fs volume create cephfs0001
$ ceph fs subvolume create cephfs0001 backup

# Create 2 users rw and r

$ ceph auth get-or-create client.rw mon 'allow r' mds 'allow rw path=/' osd 'allow rw tag cephfs data=cephfs0001' -o /etc/ceph/ceph.client.rw.keyring
$ ceph auth get-or-create client.r mon 'allow r' mds 'allow r path=/backup' osd 'allow r tag cephfs data=cephfs0001' -o /etc/ceph/ceph.client.r.keyring

# Copy the keyring to client and mount it

$ scp /etc/ceph/ceph.client.rw.keyring /etc/ceph/ceph.client.r.keyring root@client.domains.example.com:/etc/ceph
$ ssh client.domains.example.com
$ mkdir /mnt/cephfs
$ mount -t ceph server1.domain8.example:/ /mnt/cephfs -o name=rw
$ df -h

Configure Object Storage with RADOS Gateway S3

The s3cmd utility has been pre-installed on your RADOS Gateway host.
On your RADOS Gateway host, create an S3 user, and an S3 bucket such that the following requirements are met:
Create an S3 user with UID: Ralph Access Key: 123456 and secret: 567890
Create an S3 bucket named: ex260bucket
Download the file http://utility.domain8.example.com/materials/EX260_53_file and upload it to bucket ex268bucket with the filename of my_53_file
A DNS wildcard entry for ex260bucket.server1.domain8.example.com has already been implemented.
Bucket ex260bucket should be accessible both with http://serverl.domain8.example.com/ex260bucket, and with
http://ex260bucket.server1.domain8.example.com/
Set a user quota such that the maximum amount of data that user Ralph can upload (combined total for all buckets that user Ralph owns) is 29971528 bytes
Set a bucket quota such that the of maximum number of bytes in a single bucket that user Ralph owns is 18485768 bytes and the maximum number of objects
that user Ralph may upload into a bucket is 200

***********

$ radosgw-admin user create --uid=Ralph --display-name=Ralph --access-key=123456 --secret=567890

$ dnf install awscli
$ aws configure --profile=ceph
$ aws s3api create-bucket --bucket=ex260bucket --endpoint=http://serverl.domain8.example.com:80 --profile=ceph

# Download the file and copy it bucket

$ wget http://utility.domain8.example.com/materials/EX260_53_file
	/home/ceph/EX260_53_file

$ radosgw-admin quota set --uid=Ralph --quota-scope=user --max-size=2899999999999999

$ radosgw-admin quota set --uid=Ralph --quota-scope=bucket --max-size=19999999999 --max-objects=200
$ radosgw-admin quota enable --uid=Ralph --quota-scope=bucket
