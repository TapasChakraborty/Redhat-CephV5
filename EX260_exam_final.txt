Devices )Configure a Ceph RADOS block device according to the following requirements:*Create a Ceph replicated pool named ex260-pool*This pool uses 32 placement groups*From this pool, create a Ceph RADOS block device image named ex260-rbd*The image size should be 512 MB*The authentication requirement is provided in another task*Format the Ceph block device image ex260-rbd with an ext4 file system*Create Satish user who can read write on ex260-pool pool.*On host client.domain8.example.com mount the Ceph block device image ex260-rbd at mount point /mnt/rbdpersistentlyAns:ceph osd pool create ex260-pool 32 32ceph osd lspoolsceph osd pool application enable ex260-pool rbdrbd pool init ex260-poolceph osd pool ls detailrbd create ex260-rbd --size 512M --pool ex260-poolrbd ls ex260-poolrbd info ex260-pool/ex260-rbdceph auth get-or-create client.satish mon 'profile rbd' osd 'profile rbd pool=ex260-pool' -o /etc/ceph/ceph.client.satish.keyringceph auth get client.satishcd /etc/cephscp ceph.client.satish.keyring client.lab.example.com:/etc/cephssh client.lab.example.comrbd map ex260-pool/ex260-rbd --id satish mkfs.ext4 /dev/rbd0mkdir -p /mnt/rbdecho "/dev/rbd0  /mnt/rbd  ext4  defaults,_netdev  0 0" >> /etc/fstabmount -asystemctl daemon-reloaddf -Th /mnt/rbdecho "ex260-pool/ex260-rbd  id=satish" >> /etc/ceph/rbdmapsystemctl enable rbdmapsystemctl start rbdmaprebootrbd showmappeddf -Th /mnt/rbd========================================================================================Question 7==========>Export an RBD Image to a FileOn server1.domains.example.com export the
